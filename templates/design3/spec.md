# Hi75C Pro — Lighting console
- **Idea** — A paper-white instrument panel: the keyboard is the one loud object, so colour appears only where the hardware emits it. Warm stock, hairline rules and a numbered rail make it feel like a lab console rather than a settings page.
- **Palette** — app paper `#F8F5EE`; rail `#EFEAE0`; cards `#FCFAF5`; hairlines `#DCD4C5` / `#CDC4B2`; ink `#23211C`; secondary `#544E43`; muted `#736C5E`; live amber `#C9762F` (selection, key glow, running dot); connected green `#3C7354`; LEDs `#F3E6CE` `#C9762F` `#C4573F` `#7E9457` `#3F8E86` `#4E6FAE` `#8A6AAE`.
- **Type** — System UI stack throughout; 31/32 h1 · 13/15 brand model · 12.5 nav · 10.5 effect names · 11.5 lede; labels 8/11 tracked caps; mono for values and metadata (8–8.5, micro 6.5–7.5); only 500/600/700 weights.
- **Spacing** — 4px base; 6/8/12/14/16/24/32 steps. 32px page gutters, 14px row gaps, 16px card padding, 6px control grid.
- **Radii & elevation** — 12 app · 10 cards · 7 controls · 6 tiles/presets · 4 keycaps; swatches and knob are round. Elevation is paper stacking: 1px borders, 1px inner highlights, a single board shadow and an amber halo; no dark chrome.
- **Active states** — Solid ink chip for the chosen effect (paper text); 1px ink ring with a 2px paper gap for the chosen swatch; paper card + inset ink rule for the active rail item; amber is reserved for "live / lit".
- **Omissions** — No window chrome, dark mode, custom colour picker, per-key editor, charts or icon library. All 17 effects and 7 colours are fixed firmware facts; the UI never invents settings.
