# LEOBOG Hi75C Pro — Lighting

**Idea** A machined control console, not a settings page: a black rail and header clamp a bone-paper field; the keyboard is the only tactile object, and the controls below read as a labelled instrument bank.

**Palette** `#0E0D0B` ink — frame, borders, type; `#EDE9DC` bone — canvas; `#FAF7EC` cream — keycaps; `#FF4B1F` signal orange — live light, selected colour, running strip; `#F2E106` acid yellow — active section, knob, action label; `#B6F500` lime — connection status only; `#E4DFCF` block fill; `#D6D0BE` slider track.

**Type** Arial Black 96/54/31/27/21/16/11 px, tracking −0.06 to −0.02 em; Arial 800 10.5 px keycap letters, 9 px effect chips; Consolas 9/8/7/6.5 px metadata, values, hex.

**Spacing** Fixed 1180×900 canvas; 4 px base; 6/8/10/12/14 px inside panels, 22–28 px at page edge; 236 px rail, 888 px main, 72 px header; console columns 430/268/182 for deliberate imbalance.

**Radii / elevation** 0 radius everywhere except the 44 px knob; 4 px panel borders, 1.5–2 px internal rules; only keycaps lift — 3 px hard black offset, no blur.

**Active state** Section = solid yellow with black type; effect and preset = solid ink with yellow index and paper type; colour = 2 px ink ring held off the swatch by a 2 px bone gap; current values echo in the orange RUNNING strip (Row Ripple / #FF4B1F / 70% / 3 of 5 / Studio).

**Omissions** No window chrome, gradients, blur, imagery, hover/focus/loading states, scroll, per-key editor, or built-out Keymap/About pages; those exist only as rail sections.
